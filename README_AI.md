# Motiva AI integration

**Status: Integrated.** A saved check-in is sent to Google Gemini, which suggests one next action. The user reviews and edits it before saving. If the AI is unavailable or its output fails validation, Motiva uses the rule-based suggestion instead. Code: `motiva/ai_suggestions.py`, called from `checkin_create` in `motiva/views_checkins.py`.

## Model

**Gemini Flash-Lite** (`gemini-flash-lite-latest`, Google's alias for the current Flash-Lite model), with the pinned **Gemini 3.1 Flash-Lite** (`gemini-3.1-flash-lite`) as a backup model, through the Google Gemini API (`google-genai` SDK) on the free tier. `GEMINI_MODEL` in `.env` holds a comma-separated list tried in order: if a model is overloaded (503), rate-limited (429), unavailable (404), or times out, the next one is tried before falling back to the rule-based action.

Why it fits:

- The task is short, structured text generation: one feasible next step from a small check-in. It does not need a large model or fine-tuning.
- A Flash-Lite model keeps response time low for an interactive form. In a test on Nov 13, 2026, with the app's exact request, Flash-Lite (latest) answered in about 1.8 s and 3.1 Flash-Lite in about 10 s, while 3.8 Flash was overloaded (503) and 3.5 Flash timed out. The thinking level is set to `low` to reduce latency.
- JSON mode with a response schema returns output that Django can parse and validate.
- A hosted API needs no GPU, model weights, or model server in the Django deployment.

## Setup

1. `python -m pip install -r requirements.txt` (adds `google-genai` and `python-dotenv`).
2. Copy `.env.example` to `.env` and set `GEMINI_API_KEY` (from Google AI Studio). `.env` is gitignored.
3. `python manage.py migrate` (adds the suggestion fields to `CheckIn`).

Without a key, the app still works and uses rule-based suggestions.

## Input

Django builds the prompt from the saved check-in only:

| Field | Source |
| --- | --- |
| goal | `CheckIn.goal` (truncated to 1,000 characters) |
| barrier | `CheckIn.barrier` (readable label) |
| available_minutes | `CheckIn.available_minutes` |
| confidence, importance, demand | `CheckIn` ratings (1–5) |
| strategies | Curated list of five strategies in `STRATEGIES` (`start`, `confidence`, `value`, `time`, `other`) |

No account identifiers are sent: no user ID, username, email, or check-in ID.

## Output

The response schema requires one JSON object:

```json
{
  "strategy": "start",
  "action": "Open the Chapter 4 slides and write three notes on reaction rates.",
  "estimated_minutes": 15,
  "rationale": "A single source and a fixed number of notes make it easy to begin."
}
```

## Django workflow

1. The user submits a valid check-in.
2. `suggest_action(checkin)` builds the prompt and calls Gemini with a 15-second timeout per model (`GEMINI_TIMEOUT_SECONDS`). While waiting, the submit button shows "Generating your next step with AI…".
3. The response is parsed and validated:
   - valid JSON with all four fields present and non-empty;
   - `strategy` is in the curated list;
   - `estimated_minutes` is an integer from 1 to `available_minutes`;
   - `action` and `rationale` are at most 300 characters.
4. The check-in is saved with the suggestion, its source (`ai` or `rule`), strategy, rationale, estimated minutes, and latency.
5. The action page (`checkin_detail`) shows the suggestion labeled **AI suggestion (generated by Gemini)** with its strategy and rationale, pre-filled in the editable action field.
6. The user edits if needed and saves. The saved text is stored in `next_action`; the original suggestion stays in `suggested_action`.

**Fallback:** if the API key is missing, the call times out, the free-tier quota is exceeded (HTTP 429), or the output fails validation, the check-in is still saved and the page shows the labeled rule-based suggestion. The fallback keeps the workflow usable. It is not the AI feature.

## Logging and data for evaluation

- Each call logs model, latency, input/output token counts, and strategy to the `runserver` console. Prompts and raw responses are not logged.
- `CheckIn.suggestion_source` and `CheckIn.ai_latency_ms` are stored, so the AI success/fallback rate and latency can be analyzed later. Comparing `suggested_action` with the saved `next_action` shows how often users edit the suggestion.
- The admin list (`/admin/`) shows source and latency per check-in.

## Resources, latency, and cost

- One API request per check-in. No local GPU or model files.
- About a few hundred input tokens (instructions, strategies, check-in) and under 100 output tokens per request.
- Free tier: no token cost, but requests per minute and per day are limited per Google Cloud project. Exceeding them returns 429, which triggers the fallback.
- On the paid tier, the cost per check-in would be a small fraction of a cent at this prompt size.
- The request blocks the redirect after a check-in, so the timeout caps the wait before the fallback is used.

## Privacy

- Only the fields listed above are sent. No account identifiers.
- The goal is free text and may contain personal details. The check-in form tells users that their input is sent to Google Gemini and asks them to avoid personal information.
- On the Gemini API free tier, Google may use submitted content to improve its products. A paid tier would be needed for stricter data handling.
- The API key is read from `GEMINI_API_KEY` and is never committed.

## Tests

`python manage.py test motiva` covers output validation (unknown strategy, minutes over the limit, empty action), saving and displaying an AI suggestion (with the model call mocked), the rule-based fallback, and a missing API key.

## Limitations

- Suggestions may be generic, off-topic, or poorly matched to the barrier. Validation checks the format, not usefulness.
- `estimated_minutes` is the model's guess, not a measured duration.
- Output varies between calls for the same input.
- Goal text could contain instructions aimed at the model. The system instruction and validation limit the effect, but cannot fully prevent it.
- Free-tier rate limits, provider overload (503), and network failures make the AI feature unavailable at times (the fallback is used).
- Motiva suggests study steps. It is not counseling or mental-health support.
